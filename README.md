# pairwise-snapshot-interp

FPS 联机一遇到丢包，敌人就瞬移：快照插值缓冲区只按到达时间排序，没有用服务器 tick 做时间轴；插值点落在两个快照之间时直接线性外推，超过 100ms 就穿墙；延迟补偿只回滚玩家位置，没有回滚碰撞体和门状态；高 ping 玩家的输入被应用到未来 tick，命中判定偏后；快照带宽没有做增量，关键帧一丢整段状态缺失；插值时钟和渲染帧没有解耦，帧率波动时敌人抖动。net/snapshot_interp.py 是核心，tests/test_snapshot_interp.py 15个红。要修的是：按服务器 tick 建时间轴；外推做上限和碰撞夹紧；延迟补偿回滚世界状态；输入按 tick 重排；增量快照加基线；插值时钟独立。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。

语言/框架：Python 3, pytest；环境可复现等级：无外部依赖。
